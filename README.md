# Homebrew Tap for Ponder

Official Homebrew tap for [**Ponder**](https://github.com/Quinnod345/ponder), a coverage-gated multi-pass review, auditing, and planning engine for coding agents (Claude Code, Codex, OpenClaw, Cursor, GitHub Copilot, and Gemini CLI).

## Install

```sh
brew install quinnod345/tap/ponder
```

Verify installation:

```sh
ponder version
ponder doctor
```
